BUILD-TIME PROTECTION
---------------------

npm run validate:redirects now runs during prebuild. It fails production builds when an edge migration redirect:

- creates a redirect chain,
- loops to itself,
- uses a trailing-slash destination,
- uses a non-site-relative URL, or
- points a known product handle at a non-canonical product path.

The final P3 production build passed this validation.
